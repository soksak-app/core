# 0.0.45 릴리즈 범위

이 계획은 0.0.45에 들어갈 열린 체크리스트 행을 정한다. 규칙은 모든 행에 적용되어, 관계없는 작업이 릴리즈를
잡아두지 않고 부분 작업이 릴리즈에 실리지 않는다.

## 규칙

0.0.45에는 다음이 들어간다.

- `main`에 이미 있고 완료로 표시된 행,
- 지금 진행 중인 branch가 있는 행: F914(gpuikit 어댑터), F915와 후속 F915-1(discovery 목록 제한 시간), F906-1(화면
  메시지 응답), F906 행 닫기,
- 릴리즈 게이트를 통과하는 데 CI가 필요로 하는 행.

그 밖의 열린 행은 바뀌지 않은 채 0.0.46 이후로 남는다.

## 이유

`main`의 체크리스트에는 열린 행이 225개 있다. 이것을 모두 끝내야 릴리즈할 수 있다고 하면 어떤 릴리즈도 나갈 수
없다. 위에 적은 행은 진행 중인 branch가 있거나 게이트에 필요하므로 이번 릴리즈에서 닫을 수 있다. 각 행은 독립된
체크리스트 항목으로 남고, 완료는 각자의 Red와 Green 증거를 따른다.
