# 글자 크기

[English](text-size.md)

예제 애플리케이션은 카드 하나나 창 전체의 글자 크기를 바꾼다. 메인 웹뷰를 확대하지 않는다. 배치와 네이티브 표면은 확대하지 않은 CSS 픽셀로 놓이므로 웹뷰를 확대하면 창 밖으로 벗어난다. 구현과 검증 상태는 [기능 목록](../features.ko.md)에 기록한다.

## 범위

범위는 사용자가 마지막으로 누른 곳이다.

- 카드(그 네이티브 터미널 영역이나 브라우저 문서 포함)를 누르면 그 카드가 범위다.
- 판 밖의 프레임(프로젝트 막대, 스페이스 막대, 프레임 크롬)을 누르면 프레임이 범위다.

창은 포커스된 카드를 범위로 시작한다. space가 열리기 전의 library처럼 포커스된 카드가 없는 창은 frame을 범위로 가진다. 그 창이 글자를 보이는 곳은 frame뿐이기 때문이다.

## 단계와 값

글자 크기는 배율이다. 단계는 0.5, 0.67, 0.75, 0.8, 0.9, 1, 1.1, 1.25, 1.5, 1.75, 2, 2.5, 3이다. 크게는 다음 큰 단계로, 작게는 다음 작은 단계로 옮기고, 기본은 1로 정한다. 3에서 크게와 0.5에서 작게는 값을 바꾸지 않는다.

- 프레임 배율은 프레임 크롬과 모든 카드에 적용한다.
- 카드 배율은 그 카드에만 적용한다.
- 카드의 실제 배율은 프레임 배율에 카드 배율을 곱한 값이다.

프레임 배율은 공통 설정 `textSize`다. 카드 배율은 카드의 레이아웃 데이터에 `textSize`로 저장되어 스페이스와 함께 저장되며, 값이 없는 카드의 배율은 1이다.

## 표시

- 프레임 크롬(프로젝트 막대와 스페이스 막대)은 프레임 배율로 CSS `zoom`을 쓰므로 줄 높이가 글자와 함께 커지고 판은 남은 높이를 받는다.
- 첫 행의 높이는 `round(max(40px, 36px × 프레임 배율))` 이고 창 제목줄이 그 행을 그리는 표시 프레임에서 같은 높이를 가지므로 창 단추는 행의 가운데에 머문다([창 단추](hosts.ko.md#창-단추)). 프레임 배율의 변경은 준비한 배치가 그린다([제목줄 높이](native-surfaces.ko.md#제목줄-높이)).
- DOM 카드의 내용은 슬롯 안에서 카드의 실제 배율로 CSS `zoom`을 쓴다. 슬롯 사각형과 네이티브 배치는 바뀌지 않는다.
- 터미널 카드는 글꼴 크기를 13포인트에 실제 배율을 곱한 값으로 정한다. 사이드카는 그 크기로 칸 크기와 열, 행을 다시 계산한다.
- 브라우저 문서 영역은 페이지 확대를 실제 배율로 정한다. 호스트는 영역을 배치하거나 표면 배율이 바뀔 때도 그 배율을 유지한다.

## 명령과 단축키

| 명령 | 효과 |
| --- | --- |
| `core.text.larger` | 현재 범위의 글자를 크게 한다 |
| `core.text.smaller` | 현재 범위의 글자를 작게 한다 |
| `core.text.reset` | 현재 범위의 글자를 배율 1로 되돌린다 |

상태 `core.text`는 `{scope: {kind: "frame"} 또는 {kind: "card", card}, frame, cards}`를 보고하며, `cards`는 각 카드 식별자를 카드 배율에 대응시킨다.

두 호스트의 View 메뉴에는 글자 크게(Command `=`), 글자 작게(Command `-`), 글자 기본 크기(Command `0`) 항목이 있다. 메뉴 단축키는 네이티브 터미널 영역이나 브라우저 문서를 포함해 어느 뷰가 키보드 포커스를 가져도 동작하며, 각 항목은 애플리케이션 주 창의 메인 페이지에서 명령을 실행하며, 애플리케이션이 한 번도 활성화되지 않아 주 창이 없으면 가장 앞의 보이는 창에서 실행한다.
