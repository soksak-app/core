# 외부 창 사이드바

[English](external-sidebars.md)

고정 변 오버라이드 계약은 V5-117-1-3-3의 잘못된 플러그인별 열과 저장 소유자를 대체한다. 수정과 녹화 앱 인수는 [기능](../features.ko.md)의 V5-117-1-3-4-7에서 미완료로 추적한다.

## 선언과 선택

플러그인은 `sidebars.window` 객체에서 `left`, `right`를 알려진 로컬 세트 ID로 지정할 수 있다. 알 수 없는 변, 객체가 아닌 매핑, 없는 세트를 거부한다. 카드 변 선언은 별도로 유지한다. 플러그인 선택은 `{place: "window-left" 또는 "window-right", plugin, set}`로 정규화한다. 일반 선택은 `{place: "left" 또는 "right", plugin: null, set}`다. 덮어쓴 선언도 모두 검증한다. 명시적 환경 목록은 기본값을 대체하고 저장 목록은 유효 목록을 대체한다.

창의 외부 사이드바는 각 변에 최대 하나이며 카드 ID는 `left`, `right`다. 플러그인 설정은 이 동일한 고정 사이드바의 내용을 오버라이드하며 다른 열을 추가하지 않는다. 포커스 내용 카드의 활성 플러그인에 선언된 오버라이드가 있으면 그것을 사용하고 없으면 일반 변 선택을 사용한다. 이는 정상 선택 우선순위이며 오류 복구가 아니다. 잘못된 참조나 없는 세트는 다른 세트를 고르지 않고 거부한다. 변에 선택이 있지만 일치하는 오버라이드와 일반 세트가 모두 없으면 고정 열을 유지하고 내용을 비운다. 비활성 플러그인 출력을 추가 사이드바로 표시하지 않는다. 섹션 탭은 선택된 세트 내부에 존재한다.

`core.settings.link`는 알려진 세트 또는 `off`를 받는다. 플러그인 링크를 제거하면 오버라이드가 없어져 일반 선택이 적용되고 일반 링크를 제거하면 일반 내용 선택이 없어진다. 이 링크에서 `inherit`는 거부한다. 기존 카드 내부 네 변의 독립 선택은 유지한다. 옛 플러그인 `left`/`right` 링크, null 세트, 레일 링크, 제거된 `cardSidebar` 위치 설정을 거부한다. 별칭이나 마이그레이션을 추가하지 않는다.

## 고정 배치와 저장

구성된 변은 고정된 전체 높이 열 하나를 차지한다. 일반 선택과 플러그인 선택은 동일한 위치와 저장 폭을 사용한다. 포커스와 활성 탭 변경은 내용과 연결 대상만 선택하며 열을 삽입·이동·리사이즈·중복 생성하지 않는다. 좌우 표시 스위치는 해당 열을 숨기며 선택과 폭을 보존한다. 전체화면은 다른 카드를 잠시 숨기며 [전체화면 계약](example-model.ko.md#카드-전체-화면)에 따라 복귀 시 배치를 돌려준다.

폭은 `windowSidebars`에 `left`, `right`만 키로 사용하고 `{width}` 레코드로 저장한다. 폭은 유한한 양수다. 플러그인 소유자는 저장하지 않는다. 오버라이드 컨텍스트는 현재 포커스 카드와 활성 탭에서 얻는다. 저장 소유자 필드, 플러그인별 사이드바 ID, 옛 레일 카드·폭·위치 데이터를 명시적으로 거부한다. 숨긴 열을 제거하고 다시 만들어도 변의 폭을 유지한다. 옛 저장 배치를 정상처럼 보이는 새 배치로 변환하지 않는다.

## 오버라이드 컨텍스트와 레일 보더

현재 적용된 플러그인 오버라이드만 고정 사이드바를 포커스 내용 카드와 활성 표면에 연결한다. 해당 카드와 탭을 `context.card`, `context.surface`로 전달한다. 일반 내용은 연결 대상이 null이며 레일 보더가 없다. 다른 플러그인을 선택하면 같은 표시에서 선택 세트·컨텍스트·레일을 갱신하고 이전 섹션을 해제한다. 섹션 상태 모듈의 선언된 우선순위는 유지한다. 필수 표면 상태나 명령이 없으면 다른 표면을 선택하지 않고 명시적인 사용 불가 상태·오류를 제공한다.

레일은 내용 카드와 오버라이드된 외부 사이드바를 묶는 경계선만 뜻한다. 실제 그린 사각형에서 계산한다. 선언된 간격을 사이에 둔 인접 사각형은 하나의 외곽선을, 분리된 사각형은 각각의 외곽선을 만든다. 일반 사이드바와 카드 내부 섹션은 레일 묶음을 만들지 않는다. 포커스 표시는 별도로 유지한다.

`core.rail`은 전체 경로와 연결된 내용 카드·고정 사이드바 ID를 식별하는 묶음을 공개한다. `core.sidebars`는 배치, 적용 플러그인 또는 null, 카드·활성 탭 또는 null, 선택 세트, 방향, 섹션 탭, 실제 표시 사각형을 공개한다. 창 사이드바 섹션은 세로 구현을 사용하고 내부 섹션은 카드 변의 방향을 따른다.

## 인수

- 좌우 열 중복, 선택된 오버라이드 우선순위, 제거할 식별자·소유자와 불필요한 레일 묶음의 수정 전 소유 Red를 유지한다. 수정 후 같은 assertion을 실행한다.
- 포커스·탭 변경에 고정 식별·위치·폭을 검증한다. 일반 내용, 플러그인 오버라이드, 유효한 빈 내용, off 선택, 저장 폭, 잘못된 데이터는 각각 검사한다.
- 다시 빌드한 양호스트는 구성된 각 변에 사이드바 하나만 표시해야 한다. 실제 섹션 탭·출력과 레일 보더를 관측하고 전체화면·복귀·설정 변경·리로드 저장을 측정하며 기계 검증 가능한 좌표·픽셀로 전체 제스처를 녹화한다.
- 현재 옛 열 테스트와 이전 녹화는 수정된 계약을 검증하지 않는다. 시간·기하·입력 완전성·정리 기준을 완화하지 않고 관련 픽스처를 수정한다. 공통 검사와 릴리스 적용은 별도 미완료 작업이다.
