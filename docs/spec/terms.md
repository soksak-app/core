# Terms

[한국어](terms.ko.md)

Each concept has one term in the code, specifications and records of every repository. A record does not give a concept a second name, and a new concept is added to the term list before it is used.

The term list is `packages/plugin-api/terms.json`. Each entry has the term, its definition and the rejected synonyms that name the same concept. `@soksak/plugin-api` ships the list, so the records check of each repository reads the same list ([records](../../AGENTS.md#documentation)).
