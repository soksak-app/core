# Terms

[한국어](terms.ko.md)

Each concept has one term in the code, specifications and records of every repository. A record does not give a concept a second name, and a new concept is added to the term list before it is used.

The term list is `terms.json` of the records kit `soksak-app/kit-records`. Each entry has the term, its definition and the rejected synonyms that name the same concept. Every repository pins the release of that kit, so the records check of each repository reads the same list, and a new term reaches a repository with the kit release that it pins ([records](../../AGENTS.md#documentation)).

The request-local declaration table is defined in [native surfaces](native-surfaces.md).
