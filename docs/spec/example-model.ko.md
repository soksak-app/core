# 예제 모델

[English](example-model.md)

예제 애플리케이션은 프로젝트, 스페이스, 탭을 관리한다. 배치 라이브러리는 카드 좌표를 관리한다.

| 객체 | 내용 |
| --- | --- |
| 프로젝트 | 루트 경로, 이름, 색상, 스페이스 |
| 스페이스 | 카드 배치, 포커스 카드, 레일 너비, 탭 |
| 카드 | 배치 슬롯, 선택적 픽셀 크기, 탭 |
| 탭 | 플러그인, 제목 |

이미 열린 프로젝트 루트를 열면 해당 프로젝트를 활성화한다. 스페이스 전환 시 현재 애플리케이션 상태를 저장하고 `Soksak.replace()`로 선택한 스페이스를 복원한다.

추가·분할 버튼은 새 탭의 플러그인을 선택한다. 카드 중앙에 탭을 드롭하면 해당 카드에 추가하고, 카드 변에 드롭하면 인접 공간을 생성한다. 카드의 유일한 탭을 이동하면 카드를 이동한다.

플러그인은 외부 문서를 `{url}`, 애플리케이션 문서를 `{page}`로 등록한다. 플러그인은 사이드바 섹션도 제공할 수 있다. 설정은 섹션 세트와 왼쪽 사이드바·플러그인 레일·오른쪽 사이드바의 세트 할당을 저장한다.

브라우저 예제는 네이티브 표면을 모사한다. 커밋 지연과 적용 오차 설정은 페이지 검증기를 검사한다. 브라우저 검사는 네이티브 합성을 검증하지 않는다. 네이티브 인수에는 [검증 절차](../operations/examples.ko.md)의 호스트 검사가 필요하다.

`plane.js`는 카드·탭 동작, `compositor.js`는 표면 사각형 측정·예측, `host.js`는 네이티브 요청, `framework/`는 런타임별 전송을 담당한다. `settings-ui.js`는 설정 DOM을 관리하고 `card.js`는 `overlay.html`과 공통으로 사용하는 입력을 처리한다.
