# 예제 모델

[English](example-model.md)

독립 창 선언·배치·연결·레일 경계선 계약은 [외부 창 사이드바](external-sidebars.ko.md)에 정의한다. 카드 내부 변 계약은 독립적으로 유지한다.

예제 애플리케이션은 프로젝트, 스페이스, 탭을 관리한다. 배치 라이브러리는 카드 좌표를 관리한다.

| 객체 | 내용 |
| --- | --- |
| 프로젝트 | 루트 경로, 이름, 색상, 스페이스 |
| 스페이스 | 카드 배치, 포커스 카드, 레일 너비, 탭 |
| 카드 | 배치 슬롯, 선택적 픽셀 크기, 탭 |
| 탭 | 플러그인, 제목 |

[프로젝트 계약](projects.ko.md)에 디렉터리 식별, 영구 저장, 설정 상속, 시작 프로젝트, 프로젝트 창을 정의한다. 스페이스 전환 시 현재 애플리케이션 상태를 기록하고 `Soksak.replace()`로 선택한 스페이스를 복원한다.

추가·분할 버튼은 새 탭의 플러그인을 선택한다. 카드 중앙에 탭을 드롭하면 해당 카드에 추가하고, 카드 변에 드롭하면 인접 공간을 생성한다. 카드의 유일한 탭을 이동하면 카드를 이동한다.

플러그인은 표면을 플러그인 패키지 안의 문서인 `{page}`로 선언하고 사이드바 섹션을 선언한다. 페이지는 문서 영역에 웹 문서를 표시한다. 선언 파일은 [플러그인 명세](plugins.ko.md)에 정의한다. 설정은 섹션 세트와 왼쪽 사이드바·플러그인 카드 왼쪽 사이드바·오른쪽 사이드바의 세트 할당을 저장한다.

카드는 내용과 상·하·좌·우 각 변에 최대 하나의 사이드바를 가진다. 카드 사이드바의 상태와 명령 경로는 하나다. 좌·우는 카드 머리 아래에서 카드 아래 끝까지 이어진다. 그 사이의 내용 열은 위에서 아래로 위 사이드바, 내용, 아래 사이드바, 내용 발을 담는다. 카드 머리는 도구 앞에 카드가 보이는 면마다 사이드바 컨트롤(`core.card.sidebar.fold`)을 위, 아래, 왼쪽, 오른쪽 순으로 하나씩 둔다. 각 컨트롤은 그 면의 `core.card.sidebar.toggle`을 실행하고 면이 펼쳐진 동안 눌린 상태이며, 면이 접혀도 머리에 남으므로 접힌 면을 거기서 다시 펼친다. 펼친 카드 사이드바는 각각 자기 면과 세트를 말하는 발 높이의 상태 줄로 끝난다(`<면> 사이드바 · <세트 이름>`, dom 이름 `core.card.sidebar.status`). 접은 면은 상태 줄을 보이지 않는다. 내용 발(`core.card.status`)은 활성 탭의 플러그인이 알린 하단 글([탭 알림](plugins.ko.md#탭-알림))과 그 뒤에 공간이 부족해 접힌 면을 보이고, 카드 아래 끝에서 내용 열만 차지하며 좌·우 사이드바의 상태 줄과 한 줄에 놓이므로, 카드의 아래 끝은 발 높이의 띠 하나다. 명시적 세트는 활성 플러그인의 기본값보다 우선하며 탭이 바뀌어도 유지된다. 명시적 세트가 없으면 플러그인 기본값을 사용한다. `core.card.sidebar.set {card, side, set}`은 알려진 세트, 해당 변을 끄는 `off`, 명시적 선택을 지우는 `inherit`을 받는다. `core.card.sidebar.toggle {card, side}`과 `core.card.sidebar.size {card, side, size}`는 기본값에서 유도한 세트를 명시 지정으로 바꾸지 않고 독립적인 접힘·크기를 저장한다. 카드 크기는 유지하며 내용은 남은 영역을 채운다. `core.grid`는 유효한 각 변을 `sidebars`로 보고한다. 분리된 inset 사이드바, panel 명령, 중복 왼쪽 열을 제거한다.

카드 배치는 변을 키로 사용하는 `data.sidebars`에 저장한다. 각 항목은 명시적 `set`, `size`, 불리언 `collapsed`를 가질 수 있다. `set`이 없으면 활성 플러그인의 기본값을 유도하며 `off`는 해당 변을 끈다. `inherit`은 명시적 세트만 지우고 배치는 유지한다. 지정된 세트의 부재, 잘못된 저장 필드·값, 오래된 `data.sidebar` 또는 `data.panels`는 명시적 오류를 낸다. 마이그레이션이나 조용한 제거는 없다. 접기는 섹션 내용만 숨기고 입력 영역이 있는 경계선 손잡이를 유지한다. 정적 잔여 폭·손잡이 영역 검사는 전체 제스처 인수와 별개다. 고정 외부 사이드바와 활성 플러그인 오버라이드는 외부 창 계약을 따르며 기존 flow/pin 위치 경로는 제거했다.

카드 사이드바 경계선은 포인터를 누를 때의 사이드바 크기에 방향별 포인터 이동량을 더한다. 왼쪽·위쪽은 카드 중앙 방향으로 커지고 오른쪽·아래쪽은 반대 방향으로 커진다. 반대편 사이드바와 카드 머리·발은 이동량에 포함하지 않는다. 크기는 선언된 사이드바 범위로 제한한다. 접힌 변을 끌면 접힌 크기에서 시작해 포인터가 최소 크기에 닿을 때 변을 열므로 경계는 포인터 아래에 있다. 끌기는 크기와 펼침 선택을 저장한다. 끌기 없는 클릭은 저장된 선택과 관계없이 열려 보이는 변을 접고 접혀 보이는 변을 연다. 경계선 입력 상자는 사이드바 안쪽 변의 내부에 있으며 잘리는 부모 밖으로 나가거나 중심이 네이티브 표면 위에 놓여서는 안 된다.

브라우저 애플리케이션은 네이티브 표면을 모사한다. 브라우저 검사는 네이티브 합성을 검증하지 않는다. 네이티브 인수에는 [검증 절차](../operations/examples.ko.md)의 호스트 검사가 필요하다.

`plane.js`는 카드·탭 동작, `compositor.js`는 표면 사각형 측정·예측, `host.js`는 네이티브 요청, 각 애플리케이션의 `runtime/index.js`는 해당 런타임의 전송, `environment.js`는 애플리케이션의 플러그인과 기본값 로드를 담당한다. `settings-ui.js`는 설정 DOM을 관리하고 `card.js`는 `overlay.html`과 공통으로 사용하는 입력을 처리한다.

## 카드 전체 화면

카드 머리에는 닫기 X 바로 앞에 전체 화면 토글이 있다. `core.card.fullscreen {card}`은 내용 카드를 일반 배치와 작업 영역 전체 사이에서 전환한다. DOM 이름은 `core.card.fullscreen`이며 접근성 이름을 명시하고 전체 화면 중에는 창 머리의 눌린 토글처럼 초점 색으로 복원 아이콘을 표시한다. `core.grid.fullscreen`은 표시된 카드 ID 또는 null을 보고하며 각 카드는 전체 화면 여부를 보고한다. 전체 화면은 저장 배치를 변경하지 않는 일시적 표시 상태다. 다른 카드와 살아 있는 표면은 폐기하지 않고 숨긴다. 같은 토글로 모든 원래 카드 기하와 상태를 복원한다. 작업 영역의 크기를 바꿔도 전체 화면을 유지한다. 구조 연산은 배치를 바꾸기 전에 일반 표시를 복원하며 다른 카드를 선택하면 일반 표시를 복원한다. 잘못된 카드와 사이드바 전용 카드는 명시적으로 실패한다. OS 창 상태는 바뀌지 않는다.

카드 사이드바의 펼침은 저장된 선택과 실제 공간 조건으로 결정한다. 한 축의 공간은 카드 크기에서 테두리(높이는 머리와 발도), 콘텐츠의 현재 레이아웃 최소 크기(현재 96포인트), 선택으로 접은 변마다의 손잡이를 뺀 크기다. 저장된 크기가 공간에 들어가는 열린 변은 그 크기로 보인다. 들어가지 않으면 저장된 크기 비율대로 줄여 보인다. 그러면 선언된 사이드바 최소 크기보다 작아지는 변이 생길 때는, 마지막으로 조작한 변(클릭이나 끌기, 조작 전에는 위나 왼쪽)을 저장된 크기 이하의 들어가는 크기로 보이고 다른 변은 자동으로 접는다. 혼자서도 최소 크기로 들어가지 않는 변은 자동으로 접는다. 폭은 좌·우, 높이는 상·하에 적용한다. 카드 상태 줄은 공간 부족으로 접힌 변을 알린다. 접힌 변은 선언된 손잡이 폭만 사용하고, 그 가운데에 변을 따라 6포인트 간격으로 놓인 지름 3포인트의 점 세 개만 grip 색(hover와 누름에서는 active grip 색)으로 그려 카드 divider의 막대 grip과 구별한다. 변을 따라 긴 선은 그리지 않는다. 그런 선은 카드 경계가 하나 더 있는 것처럼 보이기 때문이다. 전체화면·크기 변경·배치 복귀에서 매번 조건을 다시 계산한다. 세트·크기·사용자가 저장한 접힘 선택은 변경하지 않는다. core.grid는 실제 collapsed, requestedCollapsed, autoCollapsed, collapseReason과 shownSize(보이는 크기, 접힌 변은 null)를 공개한다. 공간이 생겨도 사용자가 접은 변은 접힌 상태를 유지한다.
