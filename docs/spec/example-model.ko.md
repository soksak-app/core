# 예제 모델

[English](example-model.md)

예제 애플리케이션은 프로젝트, 스페이스, 탭을 관리한다. 배치 라이브러리는 카드 좌표를 관리한다.

| 객체 | 내용 |
| --- | --- |
| 프로젝트 | 루트 경로, 이름, 색상, 스페이스 |
| 스페이스 | 카드 배치, 포커스 카드, 레일 너비, 탭 |
| 카드 | 배치 슬롯, 선택적 픽셀 크기, 탭 |
| 탭 | 플러그인, 제목 |

[프로젝트 계약](projects.ko.md)에 디렉터리 식별, 영구 저장, 설정 상속, 시작 프로젝트, 프로젝트 창을 정의한다. 스페이스 전환 시 현재 애플리케이션 상태를 기록하고 `Soksak.replace()`로 선택한 스페이스를 복원한다.

추가·분할 버튼은 새 탭의 플러그인을 선택한다. 카드 중앙에 탭을 드롭하면 해당 카드에 추가하고, 카드 변에 드롭하면 인접 공간을 생성한다. 카드의 유일한 탭을 이동하면 카드를 이동한다.

플러그인은 표면을 플러그인 패키지 안의 문서인 `{page}`로 선언하고 사이드바 섹션을 선언한다. 페이지는 문서 영역에 웹 문서를 표시한다. 선언 파일은 [플러그인 명세](plugins.ko.md)에 정의한다. 설정은 섹션 세트와 왼쪽 사이드바·플러그인 카드 왼쪽 사이드바·오른쪽 사이드바의 세트 할당을 저장한다.

카드는 내용과 상·하·좌·우 각 변에 최대 하나의 사이드바를 가진다. 카드 사이드바의 상태와 명령 경로는 하나다. 상·하는 내용 영역을 가로지르고 좌·우는 중앙의 양옆에 선다. 명시적 세트는 활성 플러그인의 기본값보다 우선하며 탭이 바뀌어도 유지된다. 명시적 세트가 없으면 플러그인 기본값을 사용한다. `core.card.sidebar.set {card, side, set}`은 알려진 세트, 해당 변을 끄는 `off`, 명시적 선택을 지우는 `inherit`을 받는다. `core.card.sidebar.toggle {card, side}`과 `core.card.sidebar.size {card, side, size}`는 기본값에서 유도한 세트를 명시 지정으로 바꾸지 않고 독립적인 접힘·크기를 저장한다. 카드 크기는 유지하며 내용은 남은 영역을 채운다. `core.grid`는 유효한 각 변을 `sidebars`로 보고한다. 분리된 inset 사이드바, panel 명령, 중복 왼쪽 열을 제거한다. 정적 사방 구현은 V5-117-1-2에서 추적하며 전체 제스처 인수는 V5-115-1에서 미완료다.

카드 배치는 변을 키로 사용하는 `data.sidebars`에 저장한다. 각 항목은 명시적 `set`, `size`, 불리언 `collapsed`를 가질 수 있다. `set`이 없으면 활성 플러그인의 기본값을 유도하며 `off`는 해당 변을 끈다. `inherit`은 명시적 세트만 지우고 배치는 유지한다. 지정된 세트의 부재, 잘못된 저장 필드·값, 오래된 `data.sidebar` 또는 `data.panels`는 명시적 오류를 낸다. 마이그레이션이나 조용한 제거는 없다. 접기는 섹션 내용만 숨기고 입력 영역이 있는 경계선 손잡이를 유지한다. 정적 잔여 폭·손잡이 영역 검사는 전체 제스처 인수와 별개다. 기존 외부 flow/pin 배치는 V5-117-1-3에서 제거가 미완료다. 방향별 모듈은 V5-117-2에서 미완료다.

브라우저 애플리케이션은 네이티브 표면을 모사한다. 브라우저 검사는 네이티브 합성을 검증하지 않는다. 네이티브 인수에는 [검증 절차](../operations/examples.ko.md)의 호스트 검사가 필요하다.

`plane.js`는 카드·탭 동작, `compositor.js`는 표면 사각형 측정·예측, `host.js`는 네이티브 요청, 각 애플리케이션의 `runtime/index.js`는 해당 런타임의 전송, `environment.js`는 애플리케이션의 플러그인과 기본값 로드를 담당한다. `settings-ui.js`는 설정 DOM을 관리하고 `card.js`는 `overlay.html`과 공통으로 사용하는 입력을 처리한다.

## 카드 전체 화면

카드 머리에는 닫기 X 바로 앞에 전체 화면 토글이 있다. `core.card.fullscreen {card}`은 내용 카드를 일반 배치와 작업 영역 전체 사이에서 전환한다. DOM 이름은 `core.card.fullscreen`이며 접근성 이름을 명시하고 전체 화면 중에는 복원 아이콘을 표시한다. `core.grid.fullscreen`은 표시된 카드 ID 또는 null을 보고하며 각 카드는 전체 화면 여부를 보고한다. 전체 화면은 저장 배치를 변경하지 않는 일시적 표시 상태다. 다른 카드와 살아 있는 표면은 폐기하지 않고 숨긴다. 같은 토글로 모든 원래 카드 기하와 상태를 복원한다. 작업 영역의 크기를 바꿔도 전체 화면을 유지한다. 구조 연산은 배치를 바꾸기 전에 일반 표시를 복원하며 다른 카드를 선택하면 일반 표시를 복원한다. 잘못된 카드와 사이드바 전용 카드는 명시적으로 실패한다. OS 창 상태는 바뀌지 않는다. 구현·검증·배포 상태는 V5-118에 기록한다.
