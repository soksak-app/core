# 기능 상태

[English](features.md)

검증 결과는 명시한 구현에만 적용한다. 테스트 통과는 배포 완료를 의미하지 않는다.

| 기능 | 구현 | 검증 | 배포 |
| --- | --- | --- | --- |
| 배치 그리기 준비 | 구현됨. 오래된 그리기 콜백을 무시함 | 그리기 리비전 변경 후 라이브러리 309/309 통과, 변이 142개 모두 검출 | 미배포 |
| 네이티브 표면 표시 | 공통 트랜잭션이 메인 문서와 표시 중인 앱 문서들을 기다림. 외부 콘텐츠는 독립적으로 렌더링. 교집합 축소 제거 | macOS 26.6.2에서 `make examples-verify` 29/29 통과. 추가 정렬 검사 4회 16/16 통과. 외부 부하 검사는 700ms 작업 구간 안에서 메인 배치가 반복 갱신되는지도 확인 | 미배포 |
| 네이티브 설정과 메뉴 | 공통 CSS 배경과 문서별 블러 구현. 복사하는 모달 스타일에서 문서 내부 효과 시트 제외 | 두 macOS 호스트의 모달 검사 12/12 통과. 설정 메뉴 전환 후 대화상자 선명도와 50% 배경 유지 포함. 외관 수동 확인 2026-09-07 | 미배포 |
| 푸터 경계선 표시 | 밝기 불일치 조사 중. 색상 변경은 적용하지 않음 | 캡처에서 밝은 선과 일반 선 확인. 두 호스트의 가로·세로 드래그 녹화에서는 밝은 선 미재현 | 미배포 |
| 네이티브 창 버튼 | 공통 AppKit 배치, 읽기 전용 좌표 조회 구현 | 두 macOS 호스트의 최대화·녹화 종료 후 좌표 검사 통과 | 미배포 |
| Windows·Linux 네이티브 호스트 | Wails 추가 웹뷰 생성 미구현. 여러 플랫폼의 CSS 정의는 공통 | 네이티브 실행 미검증 | 미배포 |

계약: [배치](spec/layout.ko.md), [표면 배치](spec/native-surfaces.ko.md), [네이티브 모달](spec/native-modals.ko.md). 절차: [빌드와 검증](operations/examples.ko.md).

2026-09-08 검증: `make verify` 통과. 라이브러리 테스트 309개, 변이 142개 검출, 문서 검사, 빌드, 생성 산출물과 커밋된 파일 비교를 포함한다.
