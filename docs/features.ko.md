# 기능 상태

[English](features.md)

검증 결과는 명시한 구현에만 적용한다. 테스트 통과는 배포 완료를 의미하지 않는다.

| 기능 | 구현 | 검증 | 배포 |
| --- | --- | --- | --- |
| 프로젝트 저장과 프로젝트 창 | [프로젝트 계약](spec/projects.ko.md) 구현: 디렉터리 중복 방지, 공통·폴더 JSON 설정, 공통 전용 열기 방식, 독립 OS 창, 배치·창 좌표 저장 | 두 macOS 호스트의 프로젝트 검사 통과. 동시 중복 열기, 상속·초기화, 창별 상태 분리, 닫기·다시 열기 복원 포함. 앱 종료 시 대기 중인 변경을 저장하고 재시작 후 저장된 프로젝트를 선택하면 작업 화면을 복원함. Go 3/3, Rust 3/3 저장소 검사 통과 | 미배포 |
| 화면 공통 외관 | 라이브러리와 작업 화면의 글자 크기 체계·자간·행간·간격·버튼·입력창·테두리·모서리·아이콘 공통화 | 두 macOS 호스트 다시 빌드. 화면 외관 비교, 기본 크기 13px·16px에서 프로젝트 이름·상태 문구의 글자 크기 일치, 글꼴·모서리 변경의 동일 적용 확인. 예제 검사 39개 통과, 실패 0개, 화면 전환 검사 2개 생략 | 미배포 |
| 프로젝트 라이브러리 | 시작·새 창에 라이브러리를 표시하고 생성·열기 시 미선택 창을 재사용. 작업 화면 복귀, 실제 배치 미리보기, 검색, 필터, 고정, 폴더 선택·생성, Git 복제, Dock 새 창 제공 | 두 macOS 호스트에서 생성·열기·복제 시 창 재사용, 디렉터리 작업 실패, Dock 동작, 열림 상태, 고정, 검색, 작업 화면 복귀, 미리보기·작업 화면 좌표 일치 검사 통과. 프로세스 재시작 시 표면을 시작하지 않고 저장된 프로젝트 목록 표시 확인 | 미배포 |
| DOM 배치 | 오래된 그리기 콜백을 무시하고 화면 해상도 변경 시 장치 픽셀 격자를 다시 그림 | 해상도 관찰 변경 후 라이브러리 310/310 통과, 변이 142개 모두 검출 | 미배포 |
| 네이티브 표면 표시 | 창별 준비가 UI 스레드의 레이어 트랜잭션을 공유함. 메인 문서와 표시 중인 앱 문서들을 기다리며 외부 콘텐츠는 독립적으로 렌더링. 프로젝트 제거 시 대기 중인 표시 처리를 완료한 뒤 표면을 제거 | 다시 빌드한 macOS 호스트에서 실제 장치 픽셀 해상도의 드래그 전체 녹화, 사이드바·레일 정렬, 외부 문서의 700ms 작업 구간 안에서 메인 배치의 반복 갱신 검사 통과 | 미배포 |
| 네이티브 설정과 메뉴 | 공통 CSS 배경과 문서별 블러 구현. 복사하는 모달 스타일에서 문서 내부 효과 시트 제외 | 두 macOS 호스트의 모달 검사 12/12 통과. 설정 메뉴 전환 후 대화상자 선명도와 50% 배경 유지 포함. 외관 수동 확인 2026-09-07 | 미배포 |
| 소수점 표면 렌더링 | macOS 콘텐츠 웹뷰가 CSS 좌표를 유지하면서 장치 픽셀 네이티브 좌표를 사용. 네이티브 배경색 변경 제거. 화면 해상도 변경 시 DOM 바인딩이 다시 그림 | 두 macOS 호스트에서 소수점 푸터, 크기 변경, 네이티브 포인터 좌표 검사 통과. 네이티브·문서의 0.5pt 단위 크기 일치. 현재 실행은 2× 화면 하나만 연결되어 화면 전환 검사를 생략했으며 이전 좌표 구현은 `1a921b4`에서 2×↔1× 전환을 통과함 | 미배포 |
| 네이티브 창 버튼 | 공통 AppKit 배치, 읽기 전용 좌표 조회 구현 | 두 macOS 호스트의 최대화·녹화 종료 후 좌표 검사 통과 | 미배포 |
| Windows·Linux 네이티브 호스트 | Wails 추가 웹뷰 생성 미구현. 여러 플랫폼의 CSS 정의는 공통 | Wails Windows 교차 컴파일 통과. Windows·Linux 네이티브 실행 미검증 | 미배포 |

계약: [프로젝트와 설정](spec/projects.ko.md), [배치](spec/layout.ko.md), [표면 배치](spec/native-surfaces.ko.md), [네이티브 모달](spec/native-modals.ko.md). 절차: [빌드와 검증](operations/examples.ko.md).

2026-09-08 프로젝트 라이브러리 검증은 두 macOS 호스트를 다시 빌드하고 재시작했다. `node --test --test-concurrency=1 examples/test`는 검사 39개 통과, 실패 0개, 화면 전환 검사 2개 생략으로 완료했다. Go 3/3·Rust 3/3 저장소 검사, Wails Windows 교차 컴파일, `make docs-check`를 통과했다. 배치 라이브러리는 변경하지 않았다. 라이브러리의 `1a921b4` 기준 `make verify` 결과는 테스트 310개 통과, 변이 142개 검출이며 빌드와 생성 산출물의 커밋된 파일 비교를 포함한다.
