# 기능 상태

[English](features.md)

검증 결과는 명시한 구현에만 적용한다. 테스트 통과는 배포 완료를 의미하지 않는다.

| 기능 | 구현 | 검증 | 배포 |
| --- | --- | --- | --- |
| DOM 배치 | 오래된 그리기 콜백을 무시하고 화면 해상도 변경 시 장치 픽셀 격자를 다시 그림 | 해상도 관찰 변경 후 라이브러리 310/310 통과, 변이 142개 모두 검출 | 미배포 |
| 네이티브 표면 표시 | 공통 트랜잭션이 메인 문서와 표시 중인 앱 문서들을 기다림. 외부 콘텐츠는 독립적으로 렌더링. 교집합 축소 제거 | macOS 26.6.2에서 `make examples-verify` 35/35 통과. 드래그 전체 녹화, 사이드바·레일 정렬, 외부 문서의 700ms 작업 구간 안에서 메인 배치의 반복 갱신 포함 | 미배포 |
| 네이티브 설정과 메뉴 | 공통 CSS 배경과 문서별 블러 구현. 복사하는 모달 스타일에서 문서 내부 효과 시트 제외 | 두 macOS 호스트의 모달 검사 12/12 통과. 설정 메뉴 전환 후 대화상자 선명도와 50% 배경 유지 포함. 외관 수동 확인 2026-09-07 | 미배포 |
| 소수점 표면 렌더링 | macOS 콘텐츠 웹뷰가 CSS 좌표를 유지하면서 장치 픽셀 네이티브 좌표를 사용. 네이티브 배경색 변경 제거. 화면 해상도 변경 시 DOM 바인딩이 다시 그림 | 두 macOS 호스트에서 소수점 푸터, 크기 변경, 네이티브 포인터 좌표, 2×↔1× 화면 전환 검사 통과. 네이티브 높이 293.5pt, 문서 높이 293.5 CSS px로 측정되고 마지막 장치 픽셀에서 네이티브 입력 수신 | 미배포 |
| 네이티브 창 버튼 | 공통 AppKit 배치, 읽기 전용 좌표 조회 구현 | 두 macOS 호스트의 최대화·녹화 종료 후 좌표 검사 통과 | 미배포 |
| Windows·Linux 네이티브 호스트 | Wails 추가 웹뷰 생성 미구현. 여러 플랫폼의 CSS 정의는 공통 | 네이티브 실행 미검증 | 미배포 |

계약: [배치](spec/layout.ko.md), [표면 배치](spec/native-surfaces.ko.md), [네이티브 모달](spec/native-modals.ko.md). 절차: [빌드와 검증](operations/examples.ko.md).

2026-09-08 검증: `make verify` 통과. 라이브러리 테스트 310개, 변이 142개 검출, 문서 검사, 빌드, 생성 산출물과 커밋된 파일 비교를 포함한다.
