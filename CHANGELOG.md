- V5-96-14-6-4-7: the native paint mask no longer builds a new `data:image/svg+xml` URL per commit. Reaching that form required two measured corrections: delivering the path through a custom property makes WebKit erase the whole document when `body::before` also consumes it (a plain-page A/B reproduced the blank; the literal style node does not), and clipping `body` itself breaks drags whose pointer path crosses a hole because `clip-path` removes pointer hit-testing in the clipped region where `mask-image` was visual only — the clip therefore applies to `body::before`, the sole paint owner, one animation frame after the host's placement answer, the frame the previous asynchronous mask image effectively landed on.
